# 小窗口审美（对齐 Prism 指挥台）

参考家庭看板 [Prism](https://sandydargoport.github.io/prism/features/DASHBOARD/) 的 **Command Center / Ambient** 构图：一件事做主区，其余收成安静的轨，不做成仪表盘墙。

## 构图

1. **品牌一行**：`本机控制面`，字重明确，不靠 emoji、不靠角标贴纸。
2. **主区「正在做」**：当前步骤是唯一大字。左侧 3px 状态色条。谁在下任务、压缩回执用安静 chip。
3. **最近轨**：完成过的步骤，每条左侧细色条；模型轮次 / 本地循环用次级文字。
4. **页脚一句**：画面与长日志留在本机。

窗口宽约 360–400pt，始终不抢键盘焦点。空闲时主区写「等待第一步」，不要塞统计条。

## 色与材质

| 角色 | 色 |
| --- | --- |
| 底 | `#12151a`，可有极轻的冷灰径向氛围，禁止紫靛渐变英雄区 |
| 抬起面 | 白 4.5%–6% 透明 + 模糊，接近 Prism 的 frosted widget |
| 描边 | 白 8% |
| 主文 | `#e8eaed` |
| 次文 | `#9aa3af` / `#6b7380` |
| 进行中 | `#7eb8c9` |
| 通过 | `#6fbf8b` |
| 失败 | `#d9897a` |
| 拒绝 | `#c4a35a` |

字体：网页预览用 Plus Jakarta Sans；Mac 上用 SF Pro，字号阶梯与预览一致（主区约 16，轨内 12–13，标签 11）。

## 明确不做

- 不把截帧缩略图默认塞进主区（可进次级抽屉，默认折叠）。
- 不用圆角大彩 pill 堆、多层阴影、霓虹描边。
- 不把「正在做」做成第二套 IDE。

Linux 预览：

```bash
npm run witness -- --workspace <路径> --ui
```

打开打印出的 `http://127.0.0.1:<port>/`。Mac 原生窗口按同一 DOM 结构用 SwiftUI 重画，而不是再发明布局。
